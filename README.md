# AI Personal Study Assistant

## Description
AI Personal Study Assistant is a Python-based web application developed using Streamlit, SQLite, and Groq AI. It helps students manage their studies efficiently.

## Features
- User Registration & Login
- Forgot Password
- Add, Update & Delete Topics
- Search Topics
- Progress Dashboard
- Charts
- Daily Planner
- AI Topic Explanation
- AI Chat Assistant
- AI Quiz Generator
- CSV Export
- PDF Export

## Technologies Used
- Python
- Streamlit
- SQLite
- Groq API
- Pandas
- ReportLab
